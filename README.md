Um sistema completo e seguro de **Login e Cadastro de Usuários** desenvolvido em **Python**. O projeto simula um ambiente real de autenticação, contando com validação de dados, persistência em banco de dados e uma interface gráfica moderna e responsiva. Ideal para ser integrado como camada de segurança em sistemas mais complexos.

---

### 🚀 Funcionalidades Principais

* **Autenticação de Usuários:** Validação de credenciais de login de forma segura e eficiente.
* **Cadastro de Novos Membros:** Sistema de registro integrado com verificações para evitar duplicidade de usuários.
* **Feedback Visual:** Mensagens claras de sucesso, erro ou campos vazios direto na interface para melhorar a experiência do usuário.
* **Banco de Dados Integrado:** Armazenamento seguro das informações cadastrais locais.

---

### 🛠️ Tecnologias Utilizadas

* **[Python](https://www.python.org/):** Linguagem base para toda a arquitetura de validação e lógica do sistema.
* **Tkinter / CustomTkinter:** Utilizado para criar uma interface moderna, intuitiva e com suporte a temas (como Dark Mode).
* **SQLite / Banco de Dados:** Persistência de dados leve e veloz para o armazenamento de usuários.
